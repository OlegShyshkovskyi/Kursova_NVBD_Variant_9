Курсова робота з дисципліни: «Робота з великими базами даних» Виконав: студент групи ПМ-43, Шишковський О. І. Перевірив: Любінський Б. Б.

Опис проекту
Проект являє собою комплексну інформаційну систему класу VLDB (Very Large Databases), призначену для автоматизації операційної діяльності та інтелектуального аналізу даних міжнародного аеропорту. Система спроектована для обробки значних масивів історичних даних та побудови бізнес-аналітики на базі стеку технологій Microsoft SQL Server.

Технологічний стек
DBMS: Microsoft SQL Server (Database Engine) — зберігання та обробка реляційних даних.

ETL: SQL Server Integration Services (SSIS) — інтеграція, очищення та завантаження даних.

OLAP: SQL Server Analysis Services (SSAS) — побудова багатовимірних моделей та агрегацій.

Reporting: SQL Server Reporting Services (SSRS) — візуалізація KPI та формування аналітичної звітності.

Ключові характеристики системи
Обсяг даних: Таблиця фактів містить понад 500 000 записів про вильоти.

Часовий діапазон: Глибина архівування історичних даних складає 10 років.

Об'єкти обліку: Система підтримує роботу з авіапарком у кількості понад 500 літаків.

Персонал: Реалізовано облік екіпажів (пілотів та бортпровідників) з прив'язкою до типів повітряних суден.

Архітектура рішення
1. Операційна база даних (AirportDB)
Реляційна модель даних, нормалізована до третьої нормальної форми (3НФ). Включає довідники моделей літаків, аеропортів, маршрутну мережу та таблицю фактичних вильотів із застосуванням стратегії індексації для оптимізації запитів у великих обсягах даних.

2. Сховище даних (AirportDW)
Побудоване за архітектурою «Зірка» (Star Schema), що забезпечує високу продуктивність аналітичних запитів.

Центральна таблиця фактів: FactDepartures (метрики: кількість квитків, сумарна виручка, тривалість польоту).

Виміри: DimDate (календар), DimRoutes (географія), DimAircrafts (характеристики флоту), DimFlightStatus.

3. Система звітності (SSRS)
В рамках проекту реалізовано 5 основних звітів:

Список літаків моделі з пілотами: ієрархічний звіт з групуванням екіпажів за типом повітряного судна.

Виконані вильоти з проданими квитками: детальний аналіз фінансових результатів рейсів.

Список стюардес: кадровий реєстр персоналу аеропорту.

Завантаженість рейсів: стовпчикова діаграма на основі OLAP-даних для аналізу популярності авіамоделей.

Аналіз пунктуальності: кругова діаграма статусів рейсів (успішно виконані, затримані та скасовані).

Інструкція з розгортання
1. Підготовка баз даних
Виконати SQL-скрипти з папки SQL для створення структур баз AirportDB та AirportDW.

Запустити алгоритм масової генерації даних для наповнення таблиць історичними записами.

2. Інтеграція даних (ETL)
Відкрити проект SSIS у Visual Studio.

Налаштувати Connection Managers для з'єднання з локальним екземпляром SQL Server.

Виконати пакет для трансформації та завантаження даних у сховище.

3. Побудова аналітичної моделі (OLAP)
Розгорнути (Deploy) проект SSAS на сервері Analysis Services.

Виконати повну обробку (Process Full) куба для розрахунку агрегатів.

4. Налаштування візуалізації (SSRS)
Завантажити проект звітів на Report Server.

Налаштувати Shared Data Sources для підключення до OLAP-куба та реляційної бази.
